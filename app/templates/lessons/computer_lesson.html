LESSON 03

Computer
Fundamentals

Learn the basic concepts of computers, hardware, software and their functions.

COMPUTER BASICS

What is a Computer?

A computer is an electronic device that processes data and produces useful information.

Definition

A computer is an electronic machine that accepts data as input, processes it according to instructions, stores information and produces output.

Simple Explanation

In simple words, a computer takes information, processes it and gives us the required result.

Main Parts of a Computer

⌨️

Input Devices

Devices used to enter data into a computer. Examples include keyboard, mouse and microphone.

🧠

CPU

The Central Processing Unit processes instructions and controls computer operations.

💾

Memory

Memory stores data and instructions needed by the computer.

🖥️

Output Devices

Devices that display or produce results. Examples include monitor, printer and speakers.

Hardware and Software

Computer systems mainly consist of hardware and software.

🖥️

Hardware

Hardware refers to the physical components of a computer that we can see and touch.

Examples: Keyboard, mouse, monitor, CPU and hard disk.

💻

Software

Software is a set of programs and instructions that tells the computer what to do.

Examples: Windows, web browsers, Microsoft Word and applications.

Applications of Computers

  • Education and online learning
  • Banking and financial services
  • Healthcare and hospitals
  • Communication and social media
  • Business and offices
  • Entertainment and gaming

Key Points

01

Computers process data and produce information.

02

Hardware consists of physical components.

03

Software provides instructions to hardware.

04

Computers are used in many areas of daily life.

Real-World Example

When a student uses a laptop to attend an online class, the keyboard and mouse provide input, the CPU processes the information, the software runs the application, and the monitor displays the lesson.

Quick Review

What is Hardware?

The physical parts of a computer.

What is Software?

Programs and instructions used by a computer.

What is CPU?

The main processing unit of a computer.

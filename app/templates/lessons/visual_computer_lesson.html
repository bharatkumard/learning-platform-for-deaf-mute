Computer Basics

Learn the basic parts of a computer and understand how hardware, software, input, processing, and output work together.

What is a Computer?

A computer is an electronic device that receives information, processes it, stores it, and produces results.

📥

Input

Information is entered into the computer using devices such as a keyboard or mouse.

⚙️

Processing

The computer processes information using its processor and other components.

💾

Storage

Information can be saved for later use on storage devices.

📤

Output

The computer presents results through devices such as a monitor or speakers.

Computer Hardware

Hardware refers to the physical parts of a computer that we can see and touch.

🖥️ Monitor

Displays visual information from the computer.

⌨️ Keyboard

Allows users to enter text, numbers, and commands.

🖱️ Mouse

Allows users to point, select, click, and interact with items on the screen.

🧠 CPU

The Central Processing Unit performs instructions and helps process information.

Computer Software

Software consists of programs and instructions that tell a computer what to do.

🪟

Operating System

Manages computer hardware and provides a platform for applications.

🌐

Applications

Programs that help users perform specific tasks, such as browsing or writing documents.

🧰

Utilities

Programs that help maintain, manage, or protect a computer system.

💻

Programs

Sets of instructions that allow computers to perform different tasks.

Real-World Example

Sending a message using a computer.

💬 Writing and Sending a Message

First, you type a message using the keyboard. This is the input.


The computer processes your instructions and prepares the message.


The message is displayed on the monitor, which is an example of output.


The message or related information may also be stored on the computer or an online service.

Quick Review

Remember these important ideas.

  • A computer receives, processes, stores, and produces information.
  • Input devices allow information to enter a computer.
  • The CPU helps process instructions.
  • Output devices present information to users.
  • Hardware refers to physical computer components.
  • Software consists of programs and instructions.

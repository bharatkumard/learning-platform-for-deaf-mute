Internet Technology

Understand how the Internet, websites, browsers, URLs and search engines work through simple visual explanations.

🌐 What is the Internet?

The Internet is a worldwide network that connects computers, phones, servers and other devices so they can communicate and exchange information.

💻

Computer

A device that can connect to the Internet.

📡

Network

Connects devices so information can travel.

🖥️

Server

Provides information and services to other devices.

🌍

Internet

A global network connecting many networks.

🌎 Web Browsers

A web browser is software that allows you to open and interact with websites on the Internet.

🌐 Browser

Software used to access websites.

📄 Web Page

A document displayed inside a browser.

🔗 Link

A clickable connection to another page or resource.

🔍 Search

A way to find information available on the web.

🛡️ Basic Internet Safety

Using the Internet safely is important when learning, communicating and sharing information online.

Remember These Basic Rules:

  • Keep passwords private.
  • Be careful when sharing personal information.
  • Use trusted websites when possible.
  • Do not click suspicious links.
  • Tell a trusted adult if something online makes you uncomfortable or unsafe.

🧠 Quick Review

  • A web browser is used to access websites.
  • A URL is an address for an Internet resource.
  • Search engines help users find information online.
  • Internet safety helps protect users and their information.

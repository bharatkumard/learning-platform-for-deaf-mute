LESSON 04

Internet and
Web Technology

Learn the basics of the internet, websites, web pages and web technologies.

WEB BASICS

What is the Internet?

The internet is a global network that connects computers and devices around the world.

Definition

The Internet is a worldwide network of interconnected computers and devices that communicate and exchange information using standard communication protocols.

Simple Explanation

In simple words, the internet allows people and devices to communicate, share information and access online services from different locations.

What is the Web?

The World Wide Web, commonly called the Web, is a collection of interconnected websites and web pages that can be accessed through the internet.

Basic Web Technologies

🏗️

HTML

HTML is used to create the structure and content of a web page.

🎨

CSS

CSS is used to control the appearance, layout and design of web pages.

⚙️

JavaScript

JavaScript adds interaction and dynamic behaviour to websites.

🌐

Web Browser

A browser allows users to access and interact with websites.

How a Website Works

01

User

The user enters a website address or searches for information.

→
02

Browser

The browser sends a request to the web server.

→
03

Server

The server processes the request and sends the required data.

→
04

Web Page

The browser displays the website to the user.

Examples of Web Services

  • Online education platforms
  • Search engines
  • Social media platforms
  • Online banking
  • E-commerce websites
  • Video streaming services

Applications of Internet Technology

Education

Students can access online courses, digital books and learning resources.

Communication

People can communicate using email, messaging and video conferencing.

Business

Businesses use websites and online services to reach customers.

Entertainment

Users can access videos, music, games and other digital content.

Key Points

01

The internet connects computers and devices around the world.

02

The Web is a collection of websites and web pages.

03

HTML, CSS and JavaScript are important web technologies.

04

Web technologies support education, communication, business and entertainment.

Real-World Example

When a student opens an online learning website, the browser sends a request to the website's server. The server sends the required web page and the browser displays the learning content to the student.

Quick Review

What is HTML?

HTML creates the structure of a web page.

What is CSS?

CSS controls the design and appearance of a web page.

What is JavaScript?

JavaScript adds interaction and dynamic behaviour to websites.

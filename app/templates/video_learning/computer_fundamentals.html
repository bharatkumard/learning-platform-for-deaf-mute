Key Learning Outcome: Understand the basic components of a computer, the difference between hardware and software, and how computers process, store, and present information.

📘 What Is a Computer?

A computer is an electronic device that accepts data, processes it according to instructions, stores information and produces results.

⌨️ Input

Data enters through devices such as a keyboard, mouse or scanner.

⚙️ Processing

The CPU processes data and carries out program instructions.

🖥️ Output

Results are presented through a monitor, printer or speakers.

💾 Storage

Files and information are kept on devices such as SSDs or hard drives.

🧩 Hardware and Software

Hardware

Hardware refers to the physical parts of a computer, such as the monitor, keyboard, CPU, memory and storage devices.

Software

Software is the collection of programs and instructions that tell a computer what to do. Examples include operating systems, web browsers and educational applications.

🧠 Important Computer Components

  • CPU: Executes instructions and processes data.
  • RAM: Temporarily holds information being used.
  • Storage: Keeps files and programs for later use.
  • Motherboard: Connects major computer components.
  • Operating system: Manages hardware and software resources.

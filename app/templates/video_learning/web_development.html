📘 What Is Web Development?

Web development is the process of creating and maintaining websites and web applications. Websites can be used for education, communication, shopping, entertainment and many other activities.

🌐 Frontend

The part of a website that users see and interact with, including text, images, buttons and menus.

⚙️ Backend

The part that handles requests, processes information and communicates with databases or other services.

🗄️ Database

A place where website information, such as user accounts or learning records, can be stored and managed.

🧩 The Three Main Web Technologies

🧱 HTML

HTML provides the structure of a webpage. It organises headings, paragraphs, images, links, forms and other page elements.

🎨 CSS

CSS controls the appearance of a webpage, including colours, fonts, spacing, borders and page layout.

💡 JavaScript

JavaScript adds interactive behaviour, such as responding to button clicks, validating forms and updating webpage content.

🔄 How Does a Website Work?

A website uses a browser and, in many cases, a web server to deliver content to users.

  1. Request: A user enters a website address or clicks a link.
  2. Server response: The browser requests the webpage and receives the required files from a server.
  3. Rendering: The browser interprets HTML, CSS and JavaScript to display the page.
  4. Interaction: The user reads content, clicks buttons, follows links or fills in forms.

♿ Accessible Web Design

Accessible web design helps people with different abilities use websites. Accessibility should be considered while building the website, not only after it is completed.

  • Use clear headings and simple, understandable language.
  • Add meaningful alternative text to informative images.
  • Provide captions and transcripts for video content.
  • Make links, forms and buttons usable with a keyboard.
  • Use readable text and sufficient colour contrast.
  • Provide clear labels and instructions for form fields.
